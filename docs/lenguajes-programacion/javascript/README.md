# JavaScript

## Secciones

1. [Fundamentos](01-fundamentos/) — Sintaxis, variables, tipos, scope, hoisting
2. [ES6+](02-es6-plus/) — Arrow functions, destructuring, modules, iterators, proxies
3. [Avanzado](03-avanzado/) — Closures, this, prototipos, herencia, patrones de diseño
4. [Asincronía](04-asincronia/) — Event Loop, promises, async/await, fetch, streams
5. [DOM y Browser](05-dom-browser/) — DOM, eventos, storage, service workers, canvas
6. [Rendimiento](06-rendimiento/) — Memory, profiling, throttling, web workers, lazy loading
7. [Arquitectura](07-arquitectura/) — Clean Code, SOLID, testing, TypeScript, seguridad
8. [Ecosistema](08-ecosistema/) — npm, bundlers, ESLint, git, CI/CD
9. [Especialización](09-especializacion/) — Engine internals, metaprogramación, Node.js, frameworks
10. [Soft Skills](10-soft-skills/) — Debugging, code review, mentoring, documentación

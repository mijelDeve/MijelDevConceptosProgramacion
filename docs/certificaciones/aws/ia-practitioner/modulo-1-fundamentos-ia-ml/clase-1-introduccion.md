# Fundamentos de IA y Machine Learning: Conceptos Clave

## Inteligencia Artificial (IA)

Es el campo amplio de la informática dedicado a crear sistemas capaces de realizar tareas que normalmente requieren inteligencia humana, como el razonamiento, el aprendizaje y la resolución de problemas.

## Machine Learning (ML)

Es un subconjunto de la IA. En lugar de programar reglas explícitas, el sistema aprende patrones a partir de datos para realizar predicciones o decisiones sobre datos nuevos.

## Deep Learning (DL)

Un subconjunto avanzado del ML inspirado en la estructura del cerebro humano (redes neuronales artificiales). Es especialmente eficaz para procesar datos no estructurados como imágenes, audio y texto complejo.

## Algoritmos y Tipos de Aprendizaje

- **Aprendizaje Supervisado**: El modelo entrena con datos etiquetados (ejemplo: correos marcados como "spam" o "no spam").
- **Aprendizaje No Supervisado**: El modelo busca patrones ocultos en datos no etiquetados (ejemplo: segmentación de clientes por comportamiento).
- **Aprendizaje por Refuerzo**: El modelo aprende mediante un sistema de recompensas y castigos al interactuar con un entorno.

## Cuestionario

- **¿Cuál es la relación jerárquica principal entre Inteligencia Artificial, Machine Learning y Deep Learning?**::La IA es el campo general, el Machine Learning es un subconjunto de la IA, y el Deep Learning es un subconjunto específico del Machine Learning basado en redes neuronales.
- **¿Qué define principalmente al Aprendizaje Supervisado?**::Es aquel donde el modelo se entrena utilizando conjuntos de datos que ya están etiquetados, permitiendo al sistema aprender la relación entre la entrada y la salida esperada.
- **¿Cuál es la principal diferencia entre el Aprendizaje Supervisado y el No Supervisado?**::El Aprendizaje Supervisado requiere datos etiquetados para predecir un resultado, mientras que el No Supervisado trabaja con datos no etiquetados para identificar patrones o estructuras ocultas automáticamente.
- **¿Por qué se considera al Deep Learning especialmente útil para procesar imágenes o lenguaje?**::Porque utiliza redes neuronales profundas que pueden aprender representaciones complejas y jerárquicas de datos no estructurados que los algoritmos de ML tradicionales no podrían manejar fácilmente.
- **¿Qué tipo de aprendizaje utiliza un sistema de recompensas y castigos para optimizar su toma de decisiones?**::Aprendizaje por Refuerzo.
- **¿En qué se diferencia el Machine Learning de la programación tradicional basada en reglas?**::En la programación tradicional, un humano escribe las reglas lógicas manualmente; en el Machine Learning, el sistema deduce esas reglas automáticamente a partir de los datos.
- **¿Cuál es el objetivo principal de la fase de entrenamiento en un modelo de ML?**::El objetivo es ajustar los parámetros internos del modelo (pesos) para que minimice el error entre sus predicciones y los resultados reales presentes en los datos.
- **¿Qué componente del Deep Learning intenta imitar la estructura básica del cerebro humano?**::Las redes neuronales artificiales.
- **¿Qué tipo de aprendizaje utilizarías para clasificar correos electrónicos en "Promociones", "Social" o "Principal"?**::Aprendizaje Supervisado (Clasificación).
- **¿Qué es un algoritmo en el contexto de la Inteligencia Artificial?**::Es el conjunto de instrucciones o reglas matemáticas que sigue un sistema para procesar datos, aprender patrones y realizar predicciones o decisiones.
